# PCB-ruller
---
### What is this project
* This is a simple 20cm ruller made form a PCB. It has an inch scale and a pin scale on the back side. On the ruller there are many footprints of components (in many sizes) that you are most likely to use in the making of a PCB for any project. Other than that it is just a measuring tool that has a special use if you make/design PCBs. 
 <img width="1000" height="380" alt="PCB 3D front" src="https://github.com/user-attachments/assets/bbdeefba-b4c4-41cf-9fb6-7709faf123c4" />

--- 
### Why I made this project
* I made this ruller becase when I make PCBs I want to have a physical copy of the componet's footprint so that I could see how small it is and how hard it would be to soulder.
* Also I dont have a ruller at the moment so that would be a nice audition to the tools I use:).
